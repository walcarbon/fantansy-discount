# 25 - Gate 0 completion checklist

## Objetivo
Checklist de salida para permitir inicio de implementación controlada.

## Checklist obligatorio

| Item | Estado | Evidencia |
|---|---|---|
| Pricing rulebook final | Pendiente | Doc aprobado |
| Commission rulebook final | Pendiente | Doc aprobado |
| State machine técnica idempotente | Pendiente | Doc + casos prueba |
| Dataset Alpha 3 meses + expected outputs | Pendiente | Dataset versionado |
| ACL endpoint/capability matrix | Pendiente | Matriz firmada |
| Inventario técnico por plugin | Pendiente | Dossier per-plugin |
| Runbooks rollback ensayados | Pendiente | Evidencia simulacro |
| Contrato sync Woo-first cerrado | Pendiente | Spec + tests |
| Mapping AutomateWoo trigger-by-trigger | Pendiente | Matriz paridad |
| Paridad PDF MVP (docs/campos/emails/secuencial) | Pendiente | UAT aprobado |

## Criterio de paso
- Gate 0 se considera completo cuando todos los ítems estén en “Completado” con evidencia verificable.
